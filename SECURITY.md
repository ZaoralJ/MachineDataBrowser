# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report privately through
[GitHub Security Advisories](https://github.com/ZaoralJ/OpcUaBrowser/security/advisories/new).
Include steps to reproduce and the affected version. You should get a response within a few days.

## Notes

- The "Auto-trust server certificates" option disables server certificate validation; use it only on isolated
  lab networks.
- Session files never contain passwords.
- Vulnerabilities in the OPC UA stack itself should also be reported to the
  [OPC Foundation](https://github.com/OPCFoundation/UA-.NETStandard/security).
